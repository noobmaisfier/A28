**This repository is intended to be used as a configuration by NvChad users!**

- The main NvChad repository (NvChad/NvChad) is used as a plugin by this repository.
- So you simply import its modules, like `require "nvchad.options"`, `require "nvchad.mappings"`
- You can therefore delete the .git of this repository (when you clone it locally) or fork it :)
